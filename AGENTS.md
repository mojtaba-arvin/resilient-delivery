# Repository agent instructions

Before creating, amending, or reviewing commits, read [COMMIT_IDENTITY.md](COMMIT_IDENTITY.md). Maintainer-directed AI-assisted work must use the verified maintainer author identity; preserve real human contributor identities; do not use AI/bot authors or bot co-author trailers. Follow the documented, narrowly approved genuine-automation exception. Disclose AI assistance in pull requests and never rewrite historical commits.

Follow the repository's existing branch, review, test, release, and merge governance. Do not push directly to the default branch, bypass required checks, self-approve, or claim unverified results.
